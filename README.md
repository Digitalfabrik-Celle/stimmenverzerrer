# Kostüm-Stimmenverzerrer

Live-Stimmenverzerrer für Halloween- und Faschingskostüme als Web-App.
Läuft komplett im Browser (Web Audio API), es werden keine Audiodaten übertragen oder gespeichert.

**App öffnen:** https://digitalfabrik-celle.github.io/stimmenverzerrer/

12 Stimmen (Dämon, Riese, Zombie, Geist, Hexe, Kobold, Roboter, Blechmann, Alien, Funkgerät, Höhle, Normal)
plus Regler für Tonhöhe, Ringmodulation, Verzerrung, Filter, Echo, Hall, Rauschsperre.
